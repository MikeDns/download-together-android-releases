# Download Together pour Android

Une petite appli Android pour télécharger des vidéos YouTube (en MP4 ou en audio) et les garder sur ton téléphone. Elle te prévient quand une nouvelle version existe.

## Télécharger

**[Télécharger la dernière version](https://github.com/MikeDns/download-together-android-releases/releases/latest)**

Sur cette page, descends jusqu'à « Assets » et touche `Download-Together-Android-….apk`.

Besoin d'aide pour l'installer ? Lis le guide : [INSTALLATION.md](INSTALLATION.md).

## À savoir

- Utilise l'appli uniquement pour des vidéos dont tu détiens les droits.
- Android te demandera d'autoriser l'installation : c'est normal, le guide t'explique quoi faire.
- Aucune donnée n'est envoyée à personne : l'appli ne fait aucun suivi.
- Pour le PC (Windows), c'est ici : [Download Together pour Windows](https://github.com/MikeDns/download-together-releases).
